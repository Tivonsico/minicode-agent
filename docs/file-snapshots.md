# 文件快照、差异与恢复

每轮任务读取模型、执行文件工具或 Shell 之前，MiniCode 会保存授权项目的开始状态；完成、失败或停止后再保存结束状态。开始状态包括用户已有的未提交修改。快照失败时不会继续派发该轮工具；结束状态保存失败会在页面提示，开始状态仍保留。

在对话顶部点击“文件改动”，或点击每轮回复后的绿色新增、红色删除统计，可选择历史轮次、展开每个文件查看真实差异。统计比较该轮开始与结束的文件内容。它也包含同一时间段内外部程序的改动，不能据此断言每行都是模型修改的。

## 保存在哪里

文件内容存于应用数据目录 `.minicode/snapshots/<项目路径的 SHA-256>/objects.git`，轮次目录为同层 `rounds.json`。这是独立的本地 Git 对象仓库。它不使用项目的暂存区，不检出项目分支，也不会向用户正常仓库提交或推送。

每个状态都是完整文件树的无父提交。未变化的内容复用 Git 对象；开始、结束状态各有一个独立引用。轮次目录记录 session、run、turn、项目路径和快照标识。相同关联也通过 `file_snapshot_started`、`file_snapshot_completed`、`file_snapshot_restored` 事件写入当前会话存储：本地模式写会话日志，MySQL 模式写 `mc_events`，无需新建业务表。MySQL 不存文件正文，数据库备份也不会自动包含本地快照仓库。

每个项目默认保留最近 20 轮已结束任务。固定的副本、未结束轮次和待核实状态另行保留。清理时先更新目录，再删除过期 Git 引用、过期 reflog，并执行 `git gc --prune=now`。提交之间没有父链，因此早期内容不会因为仍是保留提交的祖先而无限留存。固定副本可在历史窗口“取消固定”，随后参与正常清理。

同一用户运行的新版 MiniCode 会对整轮任务持有项目锁；相同或嵌套项目串行，不相交项目可并行。仓库目录还有独立的跨进程锁，避免查看差异、保存和清理相互竞争。非协作式编辑器、其他程序仍能修改工作目录，所以恢复也会检查文件版本。

## 覆盖范围

- 只保存本轮已授权项目里的普通文件，包括新增、修改、删除及可执行标志。任务中不能更改目录授权。项目无需已有 Git 仓库。
- 遵循项目 `.gitignore`。应用内部 `.minicode`、项目 `.git`、提示词和技能目录不纳入文件恢复；沿用文件工具的敏感路径限制，包含私钥标记的内容也不保存。
- 不跟随符号链接，不保存硬链接别名、设备或其他特殊文件。单文件上限 8 MiB，超限项会显示未覆盖；项目总内容上限 256 MiB、最多 50,000 个候选文件，超过项目上限会阻止该轮开始。可用 `.gitignore` 排除构建产物和依赖缓存。
- 二进制、非 UTF-8 文件保存原始内容，可以恢复；页面明确标记，不提供虚构行数。文本使用 Git 计算新增、删除行数，单文件差异预览最多显示 200,000 个字符，统计来自完整内容。
- 不保存空目录、时间戳、扩展属性或完整 POSIX 权限。恢复时普通文件使用 0644，可执行文件使用 0755。
- 文件快照不能恢复数据库、网络请求、安装到目录外的内容及其他外部副作用。Shell 继续遵守原有沙箱与权限限制；模型没有获得应用内部或 `.git` 写权限。

## 安全恢复

选择一轮后点击“预览恢复到此轮开始前”。页面显示“当前文件 → 开始状态”的实际差异。当前文件与该轮结束状态不同的受影响项会列为后续或人工修改，必须勾选确认覆盖才能执行。预览后任何受支持文件再次变化，原预览即失效，需要重新预览。

恢复仅处理当前仍授权、仍受支持的路径。链接、敏感内容、当前忽略文件及文件/目录类型冲突不会被静默覆盖。恢复前自动保存并固定当前文件状态；逐文件替换前再次验证当前内容。执行中冲突会停止剩余恢复，已经恢复的文件可通过这份固定副本查看和恢复。

恢复作为用户操作记录在现有执行日志中，复用本地执行标记或 MySQL 工作区声明。若执行结果未确认，原有操作核实入口会阻止后续派发。异常退出留下的开始快照不会被清理；没有保存的结束状态不能冒充真实结束状态，也不能直接用它执行恢复。

重要成果仍应由用户手动进行正常 Git 提交。自动快照是近期文件恢复手段。

## 接口与验证

接口位于 `/api/sessions/{sid}/file-snapshots`：GET 列出仍保留且当前授权的轮次；`/{project_id}/{round_id}` 查看差异；POST `/preview` 生成恢复影响和版本 token；POST `/restore` 携带 token 和后续修改确认；POST `/pin` 管理固定保留。

行为测试位于 `others/test/unit/test_file_snapshots.py`、`others/test/integration/test_file_snapshots.py` 及 MySQL 集成测试。覆盖用户暂存区不变、开始前脏文件、真实增删、二进制、忽略和敏感内容、实际对象回收、冲突/过期预览、停止、文件工具和真实沙箱 Shell。
