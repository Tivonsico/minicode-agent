## Harness 修复

- permission_context 固定一句说 Shell 不可用，动态一句又说已验证可用；现在只按实际状态描述。
- 任务执行器过去只发送需求文字，初始文件名虽在前端显示却未进入模型输入。现在统一通过 task_input.py 提供初始文件清单与现有接口约束，不提供验收参数或预期答案。中间重跑也出现游程编码写到新文件，因此该轮停止并保存为取消报告，完整基线重新开始。
- 原轨迹 27 次工具失败中，18 次为 xcode-select 占位程序错误、2 次其他 Shell 失败、7 次 stale_read。净化环境未优先提供应用实际 Python，minimal 沙箱也没有允许其独立运行时目录。
- python_runtime.py 统一定位真实解释器；净化 PATH 优先使用其 bin 目录，OS 沙箱只读允许该独立运行时。若运行时与应用目录重叠则不自动授权。应用、密钥、越界写入和网络限制保留，模型上下文与评测环境记录真实路径。
- stale_read 是写入或 Shell 后指纹失效的保护，不移除它来提分；模型需要重新读取当前版本。
