# 全局与项目提示词、技能

状态：已实现并通过自动化验证（2026-09-17）。

## 背景与目标

minicode 目前只有代码内置提示词和一处全局技能目录。用户需要每个获授权工作目录拥有自己的提示词与技能，并在终端清楚区分项目级和全局级内容。一次用户发话到最终回复视为一轮；该轮涉及多个项目时，模型应看到分别标注路径的项目资料。

## 能力

- 用户授权工作目录时，程序检查项目提示词文件和项目技能目录；缺失则建立，存在则先读取并校验。
- minicode 根目录有独立文件夹存放可编辑的全局提示词。
- 全局提示词每轮适用；项目提示词按本轮涉及的工作目录适用，多目录任务按路径分别标注。
- 每次模型请求中每份适用提示词只有一份；上下文压缩后仍保留适用提示词。
- 已安装技能分全局与项目两级；模型根据描述选择相关技能，用户也可用命令指定下一轮必须使用的技能。
- 终端命令分别浏览全局技能、项目技能和提示词，可查看、编辑并保存；直接编辑不扩大 Agent 的文件权限。
- 技能附属文本继续按技能所在目录的边界读取。

## 设计骨架与非功能要求

应用固定的安全提示词继续由代码控制，可编辑的全局及项目提示词按明确的层级和路径附加。项目配置只能来自已经授权的本地目录；不能因用户在聊天中提到路径就初始化文件。路径选择和项目资料在一轮内可随工具所触及目录扩展，写操作必须在对应项目资料进入模型上下文之后执行。用户直接在终端修改提示词或技能属于显式操作，内容不得解除应用的硬性路径与审批规则。终端编辑须可查看、保存和返回，常规测试在一分钟内完成。

## 范围外

本轮不提供网络技能安装、脚本自动执行、跨项目提示词合并成一份规则或替代既有硬权限边界。图形桌面前端另行实现。
