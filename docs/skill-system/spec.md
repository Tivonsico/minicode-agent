# 技能系统

项目级技能与全局提示词的后续扩展见 [分层提示词和技能规格](../scoped-prompts-skills/spec.md)。

状态：已实现并通过自动化验证（2026-09-17）。

## 背景与目标

minicode 需要独立、清晰的技能系统目录。用户安装技能后，Agent 应能根据技能描述判断任务相关性并自动采用；用户也能明确指定下一轮必须采用的技能。技能可附带脚本、模板和参考文件，供 Agent 在执行任务时读取。

## 能力

- 项目根目录的技能系统目录包含实现代码和已安装技能子目录。
- 程序自动发现已安装技能，并把名称和描述提供给 Agent；终端命令可浏览技能。
- Agent 根据当前任务自动选用一个或多个相关技能，选用后获得技能正文。
- 用户指定某技能时，下一轮必须加载它；该轮之后回到自动选择。
- Agent 可按需读取已选技能目录中的附属文本文件，读取不能越出该技能目录。
- 技能本身不能授予工作目录、解除文件审批或启用 Shell。
- 技能选择与使用记录随会话保存，恢复时不会把已消费的一次性指定重复用于后续轮次。

## 设计骨架与非功能要求

技能目录扫描、描述读取、正文和附属文件加载由独立技能模块负责。程序只把简短目录信息放进模型上下文；正文和附属文件在选用时按需加载，并设大小限制。用户强制指定通过终端命令排队，在下一条普通用户消息开始时消费。技能文件按不可信任务资料处理，系统权限始终优先。常规测试应在一分钟内结束。

## 范围外

本轮不提供远程下载、运行技能脚本、自动安装或技能自身的权限声明。Shell 仍需通过原有隔离门槛。
