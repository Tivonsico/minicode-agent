# 可观测验收

- [x] `uv run minicode --check-config` 不创建会话、不调用模型，不声称验证了远程服务。
- [x] 页面可以创建和加载会话；加载不调用模型、不重放工具。
- [x] 未授权应用目录的文件访问被拒绝；不同会话目录授权独立。
- [x] 输入任务后显示执行状态；同会话重复发送返回冲突。
- [x] 修改文件前页面显示原始差异，批准前文件保持不变。
- [x] 刷新页面后原审批仍可显示；错误 run ID 和重复 ticket 返回冲突。
- [x] 拒绝或取消审批后不写文件；正常完成后状态为 completed。
- [x] 真实 macOS Codex 沙箱可以写授权目录，不能读 .env 或范围外文件，不能向范围外写入。
- [x] 超时和取消命令后等待中的子进程不会继续生成测试文件。
- [x] 提示词编辑进入下一次上下文；指定技能只影响下一轮。
- [x] 相同主题在不同项目下不相互覆盖；删除记忆不因待提交任务复活。
- [x] 重启恢复压缩缓存时重新校验原消息指纹，保留新系统指令。
- [x] 页面不包含模型 API 密钥；错误 Host/Origin/令牌不能访问接口。
- [x] 浏览器完成读取 → 差异审批 → 修改 → Shell 审批 → 检查的离线流程。
- [ ] Windows/Linux 原生沙箱实机验收（代码已适配，本轮仅有 macOS 主机）。
