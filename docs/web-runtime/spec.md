# 本地网页与模块化 Runtime 重构

用户已确认开始实施，边界来自本次会话。

目标：摆脱 Windows 终端交互依赖，使浏览器负责展示和审批，后端独立保存会话和管理任务；明确对话、短期记忆、长期记忆、上下文四个域及管理层。

能力：历史会话加载、流式消息、目录授权、逐次审批、任务停止、项目记忆和删除、预算及压缩、提示词编辑、技能选择、经过验证的系统 Shell 隔离。

架构：本机 HTTP 接口与可重放事件流连接前后端；会话事实保持为唯一原始来源；短期状态和上下文摘要为派生数据；长期事实仅来自可校验的用户原话并绑定项目。

完成条件：用户通过网页完成文件任务并审批命令，刷新后保持任务与审批；旧会话可加载且不重放工具；沙箱不兼容时仍能使用文件工具；敏感配置不传到前端。

非目标：远程多人服务、完整自动崩溃续跑、多 Agent、轨迹分析系统、评测数据集、性能指标、简历指标。
